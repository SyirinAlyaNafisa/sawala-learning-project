# Mini Project: Produk List (JavaScript Fundamentals)

## Deskripsi
Project ini adalah latihan untuk mengelola dan memanipulasi data array of objects menggunakan JavaScript murni (ES Modules). Fokus latihan ini adalah menerapkan fungsi pencarian (search), filter, dan manipulasi string.

Fitur yang dibuat:
1. Menampilkan semua daftar produk.
2. Mencari produk berdasarkan nama (menggunakan `filter` dan `includes`).
3. Memfilter produk berdasarkan harga maksimal.
4. Kombinasi mencari produk sekaligus memfilter berdasarkan harga.

## Struktur File
- `data.js`: Berisi data dummy (array of objects) daftar produk.
- `index.js`: Berisi logika utama (fungsi pencarian dan filter) serta output `console.log`.

## Cara Menjalankan
Karena project ini berjalan di lingkungan Node.js dan menggunakan ES Modules (`import/export`), ikuti langkah berikut:
1. Buka terminal di dalam folder `mini-project-produk-list` ini.
2. Jalankan perintah berikut:
   ```bash
   node index.js
   ```
3. Hasil output pencarian dan filter akan muncul langsung di terminal.
