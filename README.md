_Catatan: Setiap folder mini-project dan milestone memiliki `README.md`-nya sendiri yang berisi penjelasan detail dan cara menjalankannya._

## 🛠️ Cara Menjalankan Project

Secara umum, ada dua cara untuk menjalankan project di repository ini tergantung pada jenis foldernya:

**1. Menjalankan File JavaScript Murni (Materi Harian)**
Untuk latihan harian di folder `01-javascript-fundamentals/` atau `02-async-api-typescript/` yang tidak menggunakan library eksternal, kamu bisa langsung menjalankannya lewat terminal menggunakan Node.js:

```bash
node nama-file.js
```

**2.Menjalankan Mini Project (Menggunakan Dependencies)**
Untuk folder mini-project-... (seperti REST API, React Dashboard, atau Next.js) yang memiliki file package.json, ikuti langkah berikut:

1. Buka terminal dan masuk ke dalam folder mini-project tersebut.
2. Install semua dependency:

```bash
npm install
```

3.Jalankan project sesuai perintah di README masing-masing folder. Contoh:

- Untuk Mini Project Node.js / React: npm run dev atau node index.js
- Untuk Frontend Next.js: npm run dev
- Untuk Backend Strapi: npm run develop
