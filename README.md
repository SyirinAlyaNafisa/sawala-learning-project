# Sawala-learning-project
Repository ini dipakai untuk mendokumnetasikan progress belajar Frontend Development selama PKL di SAWALA. 

## Struktur Folder
Setiap milestone punya folder sendiri dengan prefix angka sesuai urutan timeline belajar. Materi/latihan harian ada di sub-folder kecil sesuai topik, sementara output wajib (mini project) ada di folder terpisah `mini-project-...` agar mudah dibedakan.

| Milestone | Folder                           | Fokus                                           |
|---        |---                               |---                                              |
| 1         | `01-javascript-fundamentals/`    | Fondasi & JavaScript Modern                     |
| 2         | `02-async-api-typescript/`       | Async JavaScript, API & TypeScript              |
| 3         | `03-nodejs-fundamentals/`        | Node.js Fundamentals                            |
| 4         | `04-react-fundamentals/`         | React Fundamentals                              |
| 5         | `05-nextjs-strapi-final-project/`| Next.js, Atomic Component & Integrasi Fullstack |

## Cara Menjalankan
Sebagian besar file berupa script `.js` murni, dijalankan langsung lewat Node.js:
\`\`\`bash
node nama-file.js
\`\`\`
Untuk folder yang menggunakan package eksternal (02-kondisi function, 06-es-modules, mini-exercise-kalkulator, mini-project-produk-list), install dependency dulu:
\`\`\`bash
npm install
\`\`\`
